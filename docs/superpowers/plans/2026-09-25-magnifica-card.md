# Magnifica Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a one-screen iPhone "share card" for the Magnifica Humanitas reader: a looping cross-in-the-circuit background, a QR to the reader, and one Share button.

**Architecture:**
- **The page:** a static, single-page site: `index.html` with inline CSS and JS, plus a few assets. It installs to the Home Screen through a web manifest, and a small service worker keeps it usable offline.
- **Assets:** the QR is pre-rendered to `qr.svg` at build time. The background loop is encoded once by ffmpeg from the Kling clip.
- **Tests:** a Python suite drives headless Chrome through a small Node CDP script.

**Tech Stack:**
- HTML, CSS and vanilla JS;
- a service worker and a web manifest;
- ffmpeg and Pillow for assets;
- Node 22 (CDP) and Python 3 with OpenCV for tests;
- GitHub Pages via `gh`.

Spec: `docs/superpowers/specs/2026-09-25-magnifica-card-design.md`

| `tests/verify.py` | Asserts on the static files and on the browser JSON; exit 0 means pass |

### Task 2: Write the verification suite first (it must fail)

**Files:** Create `tests/browser.mjs`, `tests/verify.py`

- [ ] **Step 1: Write `tests/browser.mjs`.** This is the exact code in the repo file of the same name. It:
  - serves the project root on `127.0.0.1:8799`, with correct MIME types;
  - launches headless Chrome on `--remote-debugging-port=9335`;
  - measures at 390×844 and 375×667;
  - stubs `navigator.share`, then `navigator.clipboard`, and clicks `#share`;
  - waits for `navigator.serviceWorker.ready`, reloads, then **closes the server** (`server.close(); server.closeAllConnections()`) and reloads again to prove offline rendering;
  - prints one JSON line:
    `{vw, sw, qr:{x,y,w,h}, qrLoaded, title, se:{panelBottom,vh,sw}, shared, clipboard, controlled, offline:{panel,qrLoaded}}`.
  - It also saves `tests/out/phone-390.png`.
- [ ] **Step 2: Write `tests/verify.py`.** This is the exact code in the repo file. It checks:
  - the assets exist, and `bg.mp4` is ≤ 3 MB;
  - the required head tags (manifest, apple-touch-icon, absolute `og:image`, `poster`/`playsinline`/`muted`), and that there is no `og:url`;
  - `sw.js` precaches every static asset, and the manifest is standalone with existing icons.
  - It then runs `node tests/browser.mjs` and asserts:
    - no overflow at 390;
    - the SE panel is fully visible;
    - the share `url` equals the reader and the `text` names the encyclical;
    - the clipboard fallback contains the reader link;
    - the service worker controls the page, and the offline reload renders the QR;
    - the QR crop from the screenshot decodes to `https://juanalbertoramos.github.io/magnifica-humanitas/` (OpenCV).

### Task 4: Build the page, manifest and service worker until the suite passes

**Files:** Create `index.html`, `manifest.webmanifest`, `sw.js`

- [ ] **Step 1: `index.html`.** This is the approved `card-v3` design with these changes:
  - the QR is `<img id="qr" src="qr.svg">`;
  - the preview-only overlay CSS is removed;
  - a dark radial halo sits behind `.titles`, and the h1 drop-shadows are deeper, so "MAGNIFICA" stays legible over the bright beam;
  - there is a toast;
  - the head has the manifest, icon, theme-color, `apple-mobile-web-app-*` and OG tags (absolute `og:image`, no `og:url`);
  - "Open it here ›" uses `target="_blank" rel="noopener"`;
  - the share logic is `navigator.share(SHARE)`, falling back to a `clipboard.writeText(text + ' ' + url)` toast;
  - it calls `navigator.serviceWorker.register('sw.js')` on load.
- [ ] **Step 2: `manifest.webmanifest`**: name "Magnifica Humanitas", short_name "Magnifica", `display: standalone`, background and theme `#070a12`, with both icons.
- [ ] **Step 3: `sw.js`**: cache `magnifica-card-v1`.
  - It precaches `./`, `index.html`, `bg.jpg`, `qr.svg`, the manifest, both icons and the 3 fonts.
  - Navigations are network-first, falling back to cached `index.html`; other GETs are cache-first.
  - **`.mp4` requests are not intercepted**, because Safari streams video with Range requests. Offline, the cached poster shows instead.
- [ ] **Step 4: Run the suite**
